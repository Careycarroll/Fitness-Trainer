# Single-Leg Seated Leg Curl

1. Sit in the leg curl machine and set the pad just above one heel.
2. Secure the thigh pad and take the other foot off the platform.
3. Curl the working heel down and back as far as the machine allows.
4. Squeeze the hamstring at the end range, then return slowly without letting the stack touch down.
5. Complete all reps on one side before switching.
